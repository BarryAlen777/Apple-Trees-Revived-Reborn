# Apple-Trees-Revived-Reborn
把 1.12.2 的苹果树玩法带到 Forge 1.20.1



🌱 完整生长周期

苹果树叶上的果实拥有多阶段生长动画：

树叶开出细碎白花

花朵凋谢，长出青涩小苹果

小苹果逐渐长大、变色

成熟后右键树叶即可采摘，采摘后树叶回到开花状态

支持骨粉催熟，操作与普通农作物一致。


⚙️ 可配置项

金苹果树苗合成配方开关（默认开启）

附魔金苹果合成配方开关（默认开启）

树木自然生成概率与生物群系配置


安装

前置要求

Minecraft 1.20.1

Forge 推荐 47.1.0 及以上版本

安装步骤

下载对应版本的 Forge

将 .jar 文件放入 .minecraft/mods 文件夹

启动游戏即可
